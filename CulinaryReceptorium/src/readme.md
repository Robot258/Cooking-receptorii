# **Culinary Receptorium** 

Culinary Receptorium is a native Android mobile application designed for creating, storing, editing, and organizing personal cooking recipes. 

The application allows users to maintain a collection of recipes and ingredients using local storage. Each recipe can contain a structured list of ingredients with specified quantities and units of measurement. 

# **Main Features** 

- Create, edit, view, search, and delete recipes. 

- Manage a personal collection of ingredients. 

- Build recipe compositions from available ingredients. 

- Store data locally using SQLite. 

- Export recipes to PDF documents. 

- Create and restore backups of application data. 

# **Technologies** 

- Kotlin 

- Android Studio 

- SQLite 

- Android SDK 

- XML-based Android UI 

The application is designed to work primarily with locally stored data and does not require a permanent Internet connection for its core functionality.
